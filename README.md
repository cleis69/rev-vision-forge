# REV Growth Engine

Build a premium, modern and high-converting website for a company called REV (Real Estate Vision).

REV is not a photography agency.

REV is a Real Estate Growth Agency helping developers, real estate agencies and agents sell properties faster through premium visual production, strategic marketing, lead generation and automation.

The website must look like it was designed by a top agency such as Instrument, Pentagram or Ramotion.

The visual inspiration should combine:

• Apple

• Linear

• Stripe

• Vercel

• Arc Browser

• Porsche

• Notion

The design must feel luxurious, minimalistic and technological.

GENERAL STYLE

Everything must feel like Apple meets Stripe meets Linear.

Do not use generic real estate templates.

Do not use colorful gradients everywhere.

Use blue only to guide attention.

Make the interface extremely clean and premium.

Focus on typography, spacing, animations and high-end user experience.

The website must achieve a Lighthouse score above 95 and be fully responsive.
